Static image assets for the home screen and About résumé.

- Replace `study-cat.svg` to change the desktop cat. Keep this filename, or
  update the image path in the `CatArt` component in `src/App.jsx`.
- Replace `profile-photo.svg` with your portrait. To use a PNG or JPEG instead,
  update the `src` on the About window's portrait `<img>` in `src/App.jsx`.
